# DropRadar

DropRadar is a real-time collectible product intelligence system.

## Initial vertical
Pokemon TCG

## MVP promise
Help collectors know when desirable products are available, what they cost, where the observation came from, and whether the current price is favorable relative to clearly attributed market observations.

## Operating model
GitHub is the source-of-truth for code and project contracts. Hedy is the initial hosted runtime, data plane, scheduled-job system, staging environment, logging/QA surface, and release-control plane.

Development is intended to run autonomously. The founder should not be used as the project's router or routine decision-maker.
